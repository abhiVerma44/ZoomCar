# 🚗 ZoomCar – Car Rental & Booking Platform

> A full-stack car rental and booking platform inspired by the ZoomCar self-drive rental model, allowing users to explore vehicles, select pickup and drop-off locations, make bookings, and manage their rental experience.

---

## 📌 Overview

**ZoomCar** is a self-drive car rental platform designed to provide customers with a simple, convenient, and flexible way to rent vehicles.

The platform allows users to browse available cars, select pickup and drop-off locations, choose a rental duration, and complete their booking. It supports different vehicle categories such as **Hatchbacks, Sedans, SUVs, and Luxury Cars**.

The project focuses on providing a smooth digital rental experience through a user-friendly interface and a robust backend.

## 🎯 Project Objectives

The primary objectives of this project are:

* Build a complete car rental management platform.
* Provide a simple vehicle booking experience.
* Implement secure user authentication.
* Manage vehicle availability efficiently.
* Implement RESTful APIs using Spring Boot.
* Develop a responsive frontend using React.
* Integrate frontend and backend using REST APIs.
* Practice real-world full-stack application architecture.
